\problem{1}
Пусть $a, b$ положительные числа такие, что $a+b = 10$. Найдите максимальное значение выражения:

\begin{itemize}
    \item[a)] $ab;$
    \item[b)] $a^2 + b^2;$
    \item[c)] $\dfrac{1}{a} + \dfrac{1}{b}$
    \item[d)] $\sqrt{a} + \sqrt{b}$
    \item[e)] Пусть положительные числа удовлетворяют неравенству $a < c < d < b.$
Тогда если $ab = cd$, то $a + b > c + d.$
\end{itemize}

\problem{4}
Сумма положительных чисел $a_1, a_2, \ldots, a_n$ равна $1$. Докажите, что  

\begin{enumerate}
    \item   $\dfrac{1-a_1)(1-a_2)…(1-a_n)}{a_1a_2 \ldots a_n} \geq (n-1)^n;$
    \item  $\left( a_1 + \dfrac{1}{a_1}\right)^2 + \left( a_1 + \dfrac{1}{a_2}\right)^2 + \ldots + \left(  a_1 + \dfrac{1}{a_n}\right)^2 \geq \dfrac{(n^2+1)^2}{n};$
    \item $(1 + a_1)(2 + a_2) \ldots (n + a_n) \leq 2n!.$
\end{enumerate}
