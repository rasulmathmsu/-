\problem{1} (Задача-шутка) Какое наименьшее количество королей нужно поставить на шахматную доску, чтобы они били друг друга?

\problem{2} На встречу учеников ЭлМШ пришло N человек. Чтобы запечатлеть такое важное событие, каждый хотел иметь у себя фотографию каждого другого человека со встречи. За одно действие M человек делают по одной фотографии, а остальные позируют для них. Какое наименьшее количество действий нужно совершить, чтобы у каждого была фотография всех остальных со встречи?
  
\problem{3} Каково наибольшее количество последовательных натуральных чисел, у каждого из которых ровно четыре натуральных делителя (включая один и само число)?
