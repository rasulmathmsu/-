\problem{1}
Докажите,что если $c(a+b+c)<0$, то уравнение $ax^2+bx+c=0$ имеет корень.

\problem{2}
Дискриминанты трёх приведённых квадратных трёхчленов равны $1, 4$ и $9.$ Докажите, что можно выбрать по одному корню каждого из них так, чтобы их сумма равнялась сумме оставшихся корней.

\problem{3}
Решить уравнение  $x^8 + 4x^4 + x^2 + 1 = 0.$

\problem{4}
Решите систему уравнений:

\noindent
$\begin{cases}
    x + y + u = 4,\\
    y + u + v = -5,\\
    u + v + x = 0,\\
    v + x + y = -8.
 \end{cases}$

\problem{5}
Решить систему уравнений:

\noindent
$\begin{cases}
    xy = 1,\\
    yz = 2,\\
    zx = 8.
 \end{cases}$

\problem{6}
\textit{Неравенство Коши.} Докажите, что для любых чисел $x, y$ выполняется неравенство: 
\[x^2 + y^2 \geq 2xy \]

\problem{7} 
Докажите, что для любых чисел  $x, y, z$ выполняется неравенство:
\[x^2 + y^2 + z^2 \geq xy + yz + xz \]

\problem{8}
Докажите, что для любых неотрицательных чисел $a, b, c$ выполняется неравенство 
\[(a+b)(b+c)(a+c) \geq 8abc \]
